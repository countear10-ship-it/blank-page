# 안심海 (SeaSafe Busan)

부산 시민과 관광객을 위한 개인 맞춤형 해산물 섭취 의사결정 지원 웹앱입니다.

## 핵심 기능

- 부산 위험지도: 기장·송정·해운대·광안리·영도·자갈치·남항·다대포의 시연용 위험 상태, 관련 해산물, 패류독소·해양환경·검사 정보와 변화 그래프
- 맞춤 판정: 해산물·지역·생식/가열·보관 조건·개인 주의조건을 TypeScript 규칙 엔진으로 판정
- 보관 시뮬레이터: 사진을 브라우저 안에서만 읽고 시간·온도 기반 교육용 외관 효과와 위험 그래프 제공
- 안전 O/X 퀴즈: 검증 표시가 있는 12개 문제에서 5개 무작위 출제, 해설·출처·관련 기능 연결

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm run test
npm run build
```

## GitHub Pages 배포

`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 린트·테스트·빌드를 실행한 뒤 GitHub Pages에 `dist`를 배포합니다. `HashRouter`와 Vite의 상대 `base` 설정을 사용해 Pages 새로고침 경로 오류를 피합니다.

## 데이터와 한계

현재 지역 상태·변화 그래프는 발표용 시연 데이터이며, 각 카드에 공식 원문 링크와 기준일을 표시합니다. 실제 서비스에서는 국립수산과학원 패류독소 속보, 부산광역시 해양수산 안전검사, 해양수산부 해양환경 자료, 식품안전나라의 최신 자료로 교체해야 합니다.

건강정보와 사진은 서버로 보내지 않습니다. 사진은 실제 부패·병원균·패류독소를 판정하지 않으며, 앱은 의료 진단이나 식품 안전 보증을 대신하지 않습니다.
